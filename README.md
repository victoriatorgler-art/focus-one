# Focus One V0.2.1

## New
- Optional 300-character task description, visible on the setup and active timer screens.
- Calming teal palette for light and dark mode.
- Teal Home Screen icons.
- All V0.2 task prioritization and focus behavior retained.

## Publish
Replace the files in the root of your existing GitHub Pages repository with these files and commit. Your URL remains the same. Existing V0.2 task data uses the same local-storage keys, so it is preserved in the same browser/site origin. After GitHub deploys, fully close and reopen the Home Screen app.
