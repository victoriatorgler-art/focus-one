# Focus One V0.1

Focus on one thing at a time.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `focus-one`.
2. Upload the CONTENTS of this folder to the repository root. `index.html` must be at the root.
3. In GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
4. Choose `main` and `/ (root)`, then Save.
5. Open the published HTTPS URL on iPhone Safari.
6. Share > Add to Home Screen > Open as Web App > Add.

## Included
- Starter + custom activities
- 15/25/45/60/custom focus durations
- Visual countdown ring
- Pause/resume/end
- Background-safe end-time calculation
- Completion, 5-minute break and repeat
- Local session history and daily totals
- Light/dark mode
- PWA manifest, icons and offline app shell

## Data/privacy
Activities, timer state and history are stored locally in the browser. There is no account, analytics service or backend. Clearing site data/browser storage can erase history.

## V0.1 limitation
No background push alert when a timer expires while the web app is closed. Accurate remaining time restores when reopened.
